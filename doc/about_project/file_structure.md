# Project Structure

```text
xewe-led-os/                          # ESP32 firmware project (a project of the XeWe OS template)
│
├── xewe-led-os.ino                   # sketch: the Os, the generated modules, the product modules
├── Config.h                          # catalogue of module compile-time values (pins, max LEDs, ...)
├── xewe.toml                         # pinned core, modules, tools and library versions
├── release_matrix.csv                # the 43 chip / LED pin rows of a release
├── setup.sh                          # installs everything into build/, writes src/Modules.h and run.sh
├── run.sh                            # written by setup.sh, ignored
├── README.md, LICENSE.txt
│
├── src/                              # product modules
│   ├── Alexa/                        # Alexa (Espalexa)
│   ├── HomeAssistant/                # Home Assistant over MQTT discovery
│   ├── HomeKit/                      # Apple HomeKit (HomeSpan)
│   ├── SchedulePage/                 # schedule editor page and its JSON routes
│   └── Modules.h                     # generated by setup.sh, ignored
│
├── tests/
│   ├── unit/                         # host tests (pytest + g++)
│   ├── board/                        # board tests (xewe test)
│   └── MANUAL.md                     # checks that need a person and other devices
│
├── doc/                              # setup and troubleshooting, about the project, upgrading
│   └── media/                        # images, among them HomeKit_Connect_QR.png
├── releases/<version>/               # created by the prepare run of scripts/release.sh
│   ├── notes.txt                     # the GitHub Release text
│   └── release_card.md               # the generated test record (its logs/ are ignored)
├── scripts/release.sh                # prepare and tag a release; CI builds and publishes it
├── .github/workflows/ci.yml          # CI and release workflow
├── .agents/                          # agent workspace (WAX)
│
└── build/                            # generated by ./setup.sh, ignored
    ├── tools/                        # the xewe tools (venv)
    ├── libraries/                    # XeWeCore, FastLED, HomeSpan, Espalexa, PubSubClient, ArduinoJson, WebSockets
    ├── modules/                      # the selected xewe-os-modules (led, led-web, wifi, ...) as one library
    └── builds/<chip>/out/            # firmware images, manifest.json, meta.json, compile.log
```

The LED engine and LED web page live in the `led` and `led-web` modules of
[xewe-os-modules](https://github.com/xewe-labs/xewe-os-modules); see their READMEs.
