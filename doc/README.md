# Documentation

## User guides

Each feature has a folder in `setup_and_troubleshooting/` with `README.md`, `SETUP.md` and
`TROUBLESHOOTING.md`. These files hold placeholder text and are not written yet. Until they
are, the module READMEs in `src/` and [about_project/README.md](about_project/README.md) hold
the facts.

- [led_strip](setup_and_troubleshooting/led_strip/README.md): the LED strip.
- [wifi](setup_and_troubleshooting/wifi/README.md): Wi-Fi.
- [buttons](setup_and_troubleshooting/buttons/README.md): GPIO buttons.
- [time_and_scheduler](setup_and_troubleshooting/time_and_scheduler/README.md): time zone and schedules.
- [serial_port](setup_and_troubleshooting/serial_port/README.md): the serial console.
- [smart_home/homekit](setup_and_troubleshooting/smart_home/homekit/README.md): Apple HomeKit.
- [smart_home/alexa](setup_and_troubleshooting/smart_home/alexa/README.md): Alexa.
- [smart_home/homeassistant](setup_and_troubleshooting/smart_home/homeassistant/README.md): Home Assistant.
